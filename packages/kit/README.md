# @itspatmorgan/kit

The code itspatmorgan.com shares with Patrick's Design Studio (studio.itspatmorgan.com): theme hooks, the case study
scene player and stages, and the demos moved so far. It is an ordinary package: React components that import their own
stylesheets, and tokens as plain CSS variables in `src/tokens.css`. The site imports it from this workspace; Studio
installs it from this repository at a pinned commit.

Rules for kit code are in [agents/context/architecture.md](../../agents/context/architecture.md#the-kit).
