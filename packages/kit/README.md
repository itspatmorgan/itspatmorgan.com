# @itspatmorgan/kit

The code itspatmorgan.com shares with Patrick's Design Studio (studio.itspatmorgan.com): theme hooks, the case study
scene player and stages, and the demos moved so far. The site imports it from this workspace. Studio installs it from
this repository at a pinned commit and imports the stylesheets in `studio/`, which are scoped to its Website theme.

Rules for kit code are in [agents/context/architecture.md](../../agents/context/architecture.md#the-kit).
